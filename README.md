# dairy-cooling-bayes

Bayesian hierarchical modeling of heat stress intervention effects on dairy milk yield from observational farm data.

## Overview

This repository contains the analysis code accompanying the paper:

> **Estimating the Economic Impact of Cooling Systems on Milk Yield via Bayesian Hierarchical Modeling of Observational Farm Data**
> Leonidas Christodoulou, Spyroulla A. Mavrommati, Vasilis Symeou, Constantine Dovrolis
> (under review)

We develop a Bayesian hierarchical extension of Wood's lactation curve model to quantify the effect of a sprinkler-based cooling system installation on dairy milk yield at a commercial farm in Cyprus. The framework provides full posterior distributions over intervention effects and return on investment, and is designed to be reusable for other farms, climates, and intervention types.

## Data

The milk yield dataset is publicly available on Zenodo:

> https://zenodo.org/records/20068277

Temperature and humidity data were obtained from the [Cyprus National Open Data Portal](https://www.data.gov.cy) for the Athalassa Weather Station, Nicosia, covering the period 2013–2019.
